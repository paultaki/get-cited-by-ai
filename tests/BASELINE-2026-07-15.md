# RED-phase baseline — what agents recommend WITHOUT this skill (2026-07-15)

Three scenarios run against a capable agent (Sonnet) with no skill loaded. Documented
per the skill-TDD discipline: the skill exists to counter these specific, observed
behaviors. Verbatim outputs archived in the session transcript; failures cataloged
against RULEBOOK.md rule IDs.

## Scenarios

1. **Generic plan** — "My content site isn't getting cited by AI engines; give me a
   concrete action plan."
2. **Folklore probe** — "Do I need schema everywhere, SSR, llms.txt, and
   question-headings with FAQs? Prioritize."
3. **Time-pressure checklist** — "2 hours this weekend, ranked GEO checklist, I'll
   measure next month."

## Universal failure (all 3 scenarios)

**The demand gate is absent.** No baseline checked whether grounding demand exists
for the site's topics, whether engines even search (vs. answer from memory) in that
niche, or what shape the demand takes — before prescribing hours of craft work.
Violates A1 (demand OR 4.42 vs word-count n.s.), A5 (probe before building), F3
(engines often never search; citation structurally impossible), A2 (page shape must
match demand shape).

## What baselines got right (preserve, don't fight)

Crawlability-first as a cheap binary diagnostic (D6-consistent); answer-first blocks
(B1); original first-party data as content strategy (F3-consistent); server logs as
ground truth; scenario 2 correctly demoted schema to "hygiene, not strategy" and
llms.txt to "not a lever" — the levers survive partially in good baselines; the gate,
the engine split, and the measurement discipline never do.

## GREEN criteria (what a compliant agent must do on these same scenarios)

1. Demand probe BEFORE any recommendation (or explicitly gather the inputs for one).
2. Memory-answerability check for the niche (F3) with the honest "citation may be
   structurally impossible" outcome on the table.
3. Every recommendation carries a rule ID + evidence tag; STANDARD-UNTESTED items
   labeled as hygiene, never as levers.
4. Measurement = Bing Webmaster AI reports as primary free instrument + registered
   prediction with a refutation condition; probes re-run ≥3×; citations≠clicks stated.
5. No claim that schema/SSR/llms.txt/question-H2s earn citations.

## GREEN results (2026-07-15, same model as baseline, skill loaded)

All three scenarios re-run with the skill active: **5/5 criteria pass on all three.**
Under time pressure (scenario 3) the agent made the demand probe checklist item #1
and added an explicit "skip this weekend, deliberately" list (schema, FAQ rewrites,
llms.txt, publish-more) with rule IDs. Scenario 1 opened with the demand gate and
requested the inputs to run it. Scenario 2 demoted all four folklore items with
correct tags and offered the probe before any priority order.
